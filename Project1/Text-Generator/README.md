# ✨ AI Text Studio — AI-Powered Text Generator

AI Text Studio is a simple AI-powered writing assistant that generates text from user-provided prompts. Built using the **Qwen2.5-0.5B-Instruct** language model, Hugging Face Transformers, and Gradio, it allows users to create different types of content through an interactive web interface.

Users can generate paragraphs, short stories, essays, professional emails, and social media posts by selecting a writing style and output length.

## 1. Problem Statement

Writing content from scratch can be time-consuming, especially when users need help organizing ideas, drafting professional messages, or creating engaging content.

AI Text Studio addresses this problem by providing an easy-to-use interface that generates text based on user instructions.

**Target Users**
- Students preparing assignments and educational content.
- Content creators drafting social media posts.
- Professionals writing emails and short documents.
- Anyone looking for assistance with creative writing and everyday writing tasks.

## 2. Features

- **AI Text Generation:** Generates content based on user-provided prompts.
- **Multiple Writing Styles:** Supports Paragraph, Story, Essay, Email, and Social Media Post.
- **Adjustable Output Length:** Choose Short (80 tokens), Medium (150 tokens), or Long (250 tokens).
- **Interactive Web Interface:** Simple interface built with Gradio.
- **Prompt Validation:** Displays a warning when the prompt is empty.
- **Clear Functionality:** Clears the input fields to start a new request.
- **Instruction-Based Generation:** Uses system and user messages to guide the model's writing style.
- **Configurable Text Generation:** Uses sampling with a temperature of 0.7 and top-p of 0.9.

## 5. System Workflow

The application follows this workflow:

```text
User enters a prompt
        |
        v
Select writing style
        |
        v
Select output length
        |
        v
Validate user input
        |
        v
Build system and user messages
        |
        v
Qwen2.5-0.5B-Instruct Model
        |
        v
Generate text using Transformers
        |
        v
Display generated content
        |
        v
User reviews the output
```

### Text Generation Process

1. The user enters a topic or writing instruction.
2. The user selects a writing style and preferred output length.
3. The application checks whether the prompt is empty.
4. A suitable instruction is combined with the user's prompt.
5. The Qwen model generates a response through the Transformers pipeline.
6. The generated content is displayed in the Gradio output box.

## 7. Limitations and Safety

### Limitations

- The model may produce inaccurate, incomplete, or repetitive information.
- Output quality depends on prompt clarity and model capabilities.
- The model's relatively small size may limit performance on complex writing tasks.
- Generation speed depends on available hardware and resource usage.
- The generated response may not always follow every instruction perfectly.
- The application does not currently implement document retrieval, source citations, or fact verification.

### Safety Considerations

- Review generated content before using it in assignments, emails, or public posts.
- Verify factual claims using reliable sources.
- Do not submit confidential, personal, or sensitive information unnecessarily.
- Generated content should be treated as a draft rather than guaranteed accurate information.
- The current application does not implement a dedicated content-moderation or hallucination-detection layer.
